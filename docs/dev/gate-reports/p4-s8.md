## Why

fesm-utils `nc_read` set every value below `1e-30` in magnitude to zero. The Maxwell memories of VILMA2 hold such values (decayed high-degree slots at T170), so a restored run did not continue from the written state
(G4 at S7: `tau_*` differed at 1e-28 Pa). The same applied to every model restoring state through ncio.
