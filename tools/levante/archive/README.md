# Archived Levante scripts

The gate, regression and Yelmo-calibration scripts of the kryos development phases (phases 0-4, the gates G0-G7, S5-S11,
calib-cf, ant-friction, setup-diag), kept as they were run so that the reports in docs/dev/ stay traceable. Their paths
(`/work/ba1442/robinson/kryos-gate`, the gate stacks S*, the gate's Julia depot and tools project) are those of their
time: they are not maintained and are not meant to be run by others. The maintained tools are in the parent folder
(tools/levante/README.md).
